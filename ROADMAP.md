# Hoja de ruta de Vera

El panorama de producto y desarrollo se mantiene dentro de Vera, con cada
capacidad y entregable modelado como una tarea consultable:

**[VERA — Roadmap de producto y desarrollo](https://vera.mediafranca.net/vera-roadmap-de-producto-y-desarrollo/)**

Este archivo queda como dirección estable para enlaces del repositorio. Las
[especificaciones Allium](specs/) gobiernan el comportamiento; los planes de
[docs/](docs/README.md#planes-y-registro-de-decisiones) conservan el contexto
técnico e histórico de implementaciones concretas.

El trabajo aceptado se materializa como
[issues públicos](https://github.com/mediafranca/vera/issues), enlazados desde
la capacidad correspondiente en el roadmap. Una idea todavía no acordada se
discute primero en [GitHub Discussions](https://github.com/mediafranca/vera/discussions);
una casilla del roadmap no se considera terminada sólo porque exista código en
una rama.

Una meta deseable sin spec ni implementación todavía —que proponer un cambio a
Vera se pueda pedir en diálogo con tu propio agente, y llegue como pull
request— está anotada en
[CONTRIBUTING.md §10](CONTRIBUTING.md#10-meta-deseable-proponer-un-cambio-en-diálogo-con-tu-agente).
