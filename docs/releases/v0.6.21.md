# Vera 0.6.21 — Lucienne recibe herramientas y territorio

Este corte completa dos piezas que debían llegar juntas: Lucienne amplía su
repertorio bibliotecario y cada una de sus acciones queda cercada por el mismo
territorio que rige las demás puertas de Vera.

## Harness bibliotecario v2

- declara ocho capacidades legibles desde **Centro de Vera → Bibliotecario**;
- permite buscar, leer páginas, consultar estructura, inspeccionar relaciones y
  comprobar invariantes durante una conversación;
- permite proponer una corrección sin modificar el corpus;
- exige una confirmación humana actual para aplicar una propuesta aprobada;
- carece de herramientas destructivas.

## Territorios y superficies

- añade políticas `selected` y `all` por participante;
- distingue la biblioteca general de los espacios compartidos y sitios públicos;
- deja incluir superficies con permisos concretos o excluirlas expresamente;
- hace que una exclusión domine una inclusión cuando una página pertenece a
  varias superficies;
- aplica la misma decisión en sitio, API y MCP, incluyendo listas, búsqueda,
  consultas, relaciones, medios, historial, exportaciones y escritura;
- devuelve una explicación y una ruta de corrección cuando rechaza una acción.

## Migración

Las identidades existentes reciben una política explícita equivalente a su
alcance anterior. El harness activo pasa a v2. La migración no activa modelos,
rutinas ni permisos nuevos fuera del catálogo declarado.

## Verificación

- contrato Allium y matriz de trazabilidad actualizados;
- pruebas de migración, exclusión dominante, lectura, escritura, historial,
  exportación y gobierno territorial;
- prueba del bucle real de Lucienne: pide una herramienta, recibe una observación
  cercada y sólo entonces responde;
- TypeScript, suite completa y build web verdes.
