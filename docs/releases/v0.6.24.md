# Vera 0.6.24 — Identidad del agente de biblioteca

Este corte separa el nombre de quien ocupa el oficio de la forma en que Vera
nombra ese oficio. Lucienne permanece como valor inicial editable, no como una
identidad fija ni una elección de género impuesta por el producto.

## Identidad visible y editable

- el Centro llama **Agente de biblioteca** al oficio singular de la instancia;
- su panel muestra un campo **Nombre** y permite renombrar al participante ya
  constituido;
- el cambio conserva participante, principal humano, constitución, manifiestos,
  harness, runtime, territorio, conversaciones y autoría;
- el nombre anterior queda en la historia de la identidad;
- las conversaciones, el prompt del runtime y el registro de herramientas usan
  el nombre efectivo después del cambio.

## Personalidad sin identidad duplicada

- una instalación nueva crea la página constitutiva **Agente de biblioteca** en
  vez de bautizar esa página con el nombre inicial del participante;
- la página sigue siendo visible, editable y versionada, pero su título ya no
  funciona como un segundo campo de nombre;
- Lucienne continúa como sugerencia editable durante el primer arranque.

## Verificación

- una prueba renombra Lucienne a Aster después de constituirla y comprueba que
  el mismo agente responde, conversa y usa herramientas con el nombre nuevo;
- 1.923 pruebas, TypeScript, Allium, trazabilidad y build web verdes.
