# Vera 0.7.6 — Canvas nativo para ambos Mac

Vera 0.7.6 completa el hotfix Desktop preparando de manera explícita los
binarios de canvas para Apple Silicon e Intel antes de construir el paquete
universal de macOS. El verificador posterior exige que ambos estén presentes.

El corte conserva las correcciones anteriores: canvas incluido en los
instaladores, PDF cargado sólo cuando se usa, migración 25 idempotente y
verificación del cierre nativo en Linux, macOS y Windows.
