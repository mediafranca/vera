# Vera 0.10.2 — Releases verificables y actualización deliberada

Vera 0.10.2 incorpora procedencia verificable para los instaladores de Vera
Desktop y una comprobación manual de nuevas versiones desde la propia
aplicación. La actualización del programa sigue separada del corpus: descargar
o reemplazar Vera Desktop no modifica la memoria de la biblioteca.

## Qué cambia

- Centro de Vera → Biblioteca ofrece **Buscar actualizaciones**. Compara la
  versión instalada con la última release estable y, cuando corresponde, abre
  la página oficial de descarga.
- Cada instalador publicado lleva un bundle Sigstore *keyless*, una attestation
  de procedencia de GitHub y un checksum SHA-256 verificable.
- La identidad firmante proviene del workflow mediante OIDC efímero. El
  repositorio no almacena una clave privada de release.
- El workflow crea primero una release en borrador. Su publicación exige
  descargar y verificar los artefactos producidos.
- La documentación distingue la procedencia Sigstore de la confianza propia de
  cada sistema operativo. Windows y macOS continúan sin Authenticode,
  Developer ID ni notarización mientras esas credenciales no existan.

## Consolidación

Este corte incorpora también los cambios vigentes que habían quedado fuera de
`main`: documentación bilingüe y objetivo WCAG, separación operativa entre
desarrollo y producción, conciliación de las especificaciones de identidad y
medios, y gobierno de artefactos institucionales. Los commits obsoletos o ya
superados no se reintrodujeron.

## Verificar una descarga

Las notas de la release incluyen los comandos exactos para comprobar el
checksum, el bundle Sigstore y la attestation de GitHub. Estas pruebas permiten
confirmar qué workflow produjo el archivo y que no cambió desde entonces; no
suprimen las advertencias de SmartScreen o Gatekeeper.
