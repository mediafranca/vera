# Vera 0.6.18

Esta revisión completa el starter gobernado de 0.6.17 para las memorias que ya
habían sido inicializadas con una versión anterior.

## Actualización aditiva

- Vera Desktop comprueba el starter versionado cada vez que abre una memoria;
- una instalación creada con 0.6.16 recibe Gobierno, Propiedades, Objetos,
  Relaciones y la puerta MCP al actualizar, sin borrar ni recrear su corpus;
- las operaciones antiguas se reconocen por su identidad y quedan como
  duplicados idempotentes; sólo se aplican las adiciones de la distribución;
- una base realmente nueva sigue exigiendo una persona propietaria: la
  actualización nunca inventa identidad ni cambia la custodia existente.

Incluye las capacidades de 0.6.17: Gobierno con 36 propiedades, 16 objetos y 13
relaciones editables, y primera credencial MCP autorizable desde la interfaz.

Las pruebas cubren apertura inicial, reapertura con propietario existente,
idempotencia y rechazo de una base nueva sin propietario. GitHub ofrece además
`v0.6.18-catalina.1`, la edición Intel para macOS 10.15+ sin firma ni
autoactualización.
