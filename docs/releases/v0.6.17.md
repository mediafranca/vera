# Vera 0.6.17

Esta versión vuelve operativa una Vera recién instalada antes de que exista un
bibliotecario o una personalización del corpus.

## Gobierno inicial

- **Configuración → Gobierno** nace con índices para Conexiones, Propiedades,
  Objetos y Relaciones;
- el starter incorpora un vocabulario universal y editable de 36 propiedades,
  16 objetos y 13 relaciones, incluidas las funciones estructurales de
  pertenencia, contribución, custodia y bitácora;
- los valores pertenecen al gobierno de cada instancia: pueden ampliarse o
  corregirse sin copiar la ontología particular del corpus de Herbert;
- la inicialización conserva identificadores versionados, de modo que ampliar
  el starter no vuelve a ejecutar las operaciones antiguas.

## Primera conexión MCP

- **Configuración → Conexiones** muestra la puerta MCP aunque todavía no exista
  ninguna aplicación ni credencial;
- la persona propietaria puede crear el primer acceso, copiar su secreto una
  sola vez y conectarlo a una IA sin Cotito, terminal ni cambios de código;
- Vera Conecta permanece disponible en Desktop y la misma página explica la URL
  y el alcance de las conexiones remotas.

## Verificación

- una instalación vacía crea 13 páginas y 136 bloques de inicio;
- la ontología materializada expone 36 propiedades, 16 objetos y 13 relaciones;
- Gobierno muestra sus cinco destinos y Conexiones permite emitir una
  credencial real desde cero;
- 1.775 pruebas, TypeScript, build web y Desktop, trazabilidad y Allium pasan
  sobre el corte integrado.

Los instaladores contemporáneos conservan sus condiciones de firma. GitHub
ofrece además `v0.6.17-catalina.1`, una release especial Intel para macOS 10.15+
con Electron 32, sin firma ni autoactualización.
